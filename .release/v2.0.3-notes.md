## v2.0.3 · Danzai Noodles + Roasted Sweet Potato

Claude tabs now say exactly what the agent does, and Update Now keeps
your own commits.

### Added
- **Exact status for Claude tabs.** A Claude tab opened by tabit runs with
  tabit's Claude Code hooks, so it reports working, needs input and done
  from Claude itself instead of guessing from the screen. A long reply,
  a long command and a reply past a minute stay ▶ until Claude is really
  done, and an approved command no longer shows ? while it runs. The
  hooks add to your own Claude settings and replace none of them.
- **↻ background.** A turn that ends while sub-agents it started still run
  shows ↻ in purple, with its own popup; Claude goes on by itself when
  they finish. A sub-agent that asks for permission shows ?.

### Changed
- **Update Now keeps your own commits.** In a git checkout with commits of
  its own, it puts them on top of the new version (it merges when some
  are already pushed elsewhere) instead of failing with "divergent
  branches". Uncommitted changes are put back. It only updates `main`,
  never a rebase or merge you left half done, and on a clash it leaves
  the folder as it was and says what to run.

### Fixed
- Plain AI tabs no longer take `TMUX` from tabit's own environment.

### Notes
- Only Claude tabs opened after this release get the hooks. Open a new
  Claude tab for an older one. codex, grok and other CLIs, and older
  Claude tabs, are still read from the screen.
- Esc or Ctrl+C runs no Claude hook. tabit sees them when they are
  pressed in the tab or on the Remote page; an Esc typed into the same
  Claude from another terminal is not seen until the next prompt.
- A checkout still on v2.0.2 or older updates with the old way once. If it
  has commits of its own, update it by hand one time:
  `cd <your tabit folder> && git pull --rebase origin main && ./install.sh`
