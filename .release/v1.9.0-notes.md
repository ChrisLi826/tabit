## v1.9.0 · Bubble Tea

An AI tab that stops working now tells you, instead of leaving the news in
a sidebar glyph you have to be looking at.

### Added
- **A notification when an agent finishes or wants you.** tabit behind
  another window gets a desktop notification through libnotify *and* an
  in-app popup, so the news reaches you either way and is still there on
  coming back. tabit in front gets the popup alone — a desktop one would
  be talking over tabit's own window. Nothing pops for the tab you are
  already looking at, and nothing pops for a status that changes back
  within five seconds, which outlasts one status poll and so is detection
  wobble rather than news.
- **The popup is shaped like the tab row it is about** — the group's own
  colour bar, the same status glyph, the group and tab names, the time —
  and sits at the foot of the tab list, because that is where the eye
  goes for a tab. It covers the new-session buttons and never the AI
  status row, which is what accounts for every agent. Click anywhere on
  it to switch to that tab.
- **Nothing is thrown away to make room.** The popup waiting on your
  return is the only record that a finished agent has not been looked at;
  the status row counts it as done either way. Three get cards, and the
  rest wait behind `3 more · 1 need input ▴`, which opens the whole list
  oldest-first. **Clear all** takes the waiting ones too. Opening a tab
  any other way takes its popup down, one tab never has two, and a popup
  follows its tab — an agent back at work did not finish.
- **Settings… → AI** turns it off or drops the desktop half to an urgency
  that goes away on its own. Urgency is the only say an app has over
  that: GNOME gives every other notification four seconds and ignores the
  timeout an app asks for, so critical is the default.
- **Each sidebar button marks its own shortcut key**, the way a menu
  does — `+ (S)erial`, `+ t(M)ux`, and the letter on the end where the
  word has none — and follows an edit in **Shortcuts…**. `+ Shell` is now
  `+ (T)erminal` so its key has a letter to mark.
- **`Ctrl+Shift+E` / `Ctrl+Shift+D` / `Ctrl+Shift+M`** open a new
  connect / command / tmux session.

### Fixed
- **A huge text file no longer freezes the desktop's editor.** A 1.4MB
  single-line file locked up Text Editor, which is another GtkSourceView;
  handing it over was passing on the same freeze. Ctrl+click now asks what
  to do with one — `$EDITOR` in a tab, or Base64 decode.

### Notes
`gir1.2-notify-0.7` is needed for the desktop half and the installer pulls
it in; the in-app half works without it.

### Upgrade

```sh
cd tabit && git pull && ./install.sh
```
