## v2.3.5.2 · Sesame Oil Chicken + Iron Egg

A Claude tab no longer says "Background work still running" when nothing
it does is still running.

### Fixed
- **A watch on a published artifact kept a tab "background" for good.**
  Claude Code keeps a monitor on each artifact a session published ("live
  updates for artifact …") and arms it again when the session resumes. It
  only waits for comments, so tabit no longer counts it as work.
- **A background shell Claude Code lost stayed "running".** A live
  background shell holds its output file open. tabit now drops a listed
  shell whose output file no process holds; with nothing left, the tab is
  idle. A monitor or a sub-agent still counts as long as Claude lists it.

### Notes
- Restart tabit (or let the update do it), then refresh the chat page.
