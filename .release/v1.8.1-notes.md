## v1.8.1 · Coffin Bread

Patch release: Connect tabs now show when they run inside tmux, and
"Force reconnect" stops reconnecting the device on every restart.

### Fixes
- **Connect in tmux is visible again.** A Connect tab running inside tmux
  looked exactly like one that was not: `ICON_AI` has an `ICON_AI_TMUX`
  counterpart, `ICON_CONNECT` had none, and the `[tmux]` subtitle marker is
  stripped before the row is built. New `ICON_CONNECT_TMUX` — a teal
  transmit/receive mark in the purple tmux frame — is chosen from argv, so
  tabs restored from `sessions.json` get the frame back too.
- **"Force reconnect" is a one-off action again.** It was baked into argv as
  `sh -c "tmux kill-session ...; exec tmux new-session -s ..."`. argv is
  replayed on every start, so each restart killed the session and ran the
  whole cloud login again instead of attaching to the session already
  running — and `connect_last.json` remembered the tick, so every new
  Connect tab inherited it. Now the stale session is killed once when the
  box is ticked, argv always stores the `-A` (attach-or-create) form, and
  the tick is no longer remembered.

### Upgrade

cd tabit && git pull && ./install.sh
