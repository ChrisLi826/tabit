## v1.10.0 · Beef Noodle Soup

Your agents can now reach you on your phone, and you can answer them from
it. And an AI tab that tabit reopens comes back to its own conversation,
not just the newest one in the folder.

### Added
- **Telegram: the news on your phone.** When an agent finishes or needs
  you, a message goes to your own Telegram bot — always, or only when you
  are away from tabit. It can carry the agent's last few lines.
- **Telegram: send work back.** `/status` lists every AI tab and what it
  is doing. Write a task, tap the tab it goes to, and it is typed in.
  Reply to one of tabit's messages and the reply goes straight to that
  tab. Only tabs you gave a short name take tasks (right-click the tab →
  Telegram tasks…).
- **The answer comes back to the phone.** A task asks the agent to write
  its reply to a file, about ten lines; tabit sends that, under the task
  it answers. An agent that did not write one sends the end of its
  screen instead.
- **Settings has five pages**, and the Telegram page walks you through
  setting up a bot. Find it reads your chat id off your first message.
- **+AI asks two things:** "Create new session" (on by default) picks
  what starts now; "Resume when tabit reopens" picks what the tab does
  after a restart. The tab's rename popover changes the second one later.
- **A tab comes back to its own session.** claude and the xAI grok start
  with an id tabit picks (`--session-id`, used only when the CLI's
  `--help` lists it). codex and agy pick their own id; tabit reads it
  from the session file the running agent holds open, once the first
  message is sent, and keeps it up if you start a new one inside.

### Fixed
- **A path right after "文件:" opens with Ctrl+click.** A colon only
  stops a path after an ASCII word (`https:/`, `host:/`), not after
  Chinese text.
- **Codex and agy resume the way they resume**, also when the CLI is set
  as a path: `codex resume <id>`, `agy --conversation <id>`.

### Safety
- The bot token lives in its own file, readable only by you, and never
  appears in an error shown on screen.
- Only your one private chat can talk to tabit. An answer only goes to
  the chat and bot the task came from.
- Anything a terminal would obey as a command is stripped from a task
  before it is typed in.
- Find it will not pick an owner when more than one person has written
  to the bot.

### Notes
- The old "Start AI tabs fresh after reopening" setting is now the default
  for the second +AI box. Tabs saved by an older build keep starting
  fresh once, if it was on.
- A tab made before this release has no session id yet; open a new one
  from +AI to get one.
- If `grok` on your PATH is not the xAI Grok Build CLI, grok tabs keep
  the old behaviour (newest session in the folder).
