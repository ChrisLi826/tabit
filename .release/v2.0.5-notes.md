## v2.0.5 · Danzai Noodles + Taro Balls

Pick the Claude session you want back from a list, and a Session ID now
opens exactly that session.

### Added
- **A list of the folder's sessions in + AI.** The ▾ beside Session ID
  lists the Claude sessions of the folder that no AI tab holds, newest
  first: their title, how long ago, the start of the id, and the last
  question you asked. Hover a row to read the start of Claude's last
  reply. Click one to fill in its id. Headless runs (`claude -p`) are
  left out.

### Changed
- **"Resume session" replaces "Create new session"**, and is off by
  default: unticked starts a new session. Ticked, it continues the
  Session ID given, or else, for Claude, the newest session in the folder
  that no AI tab holds. The line under the boxes names that session. The
  Session ID row only shows while Resume session is ticked.

### Fixed
- A Session ID opens that session even when the folder already has an
  agent running in tmux. Each id gets its own tmux session; before, every
  id in such a folder opened the running one.
- An id the folder does not have is reported in the tab, which keeps a
  shell open, instead of quietly opening another session.

### Notes
- An AI tab opened before v2.0.3 runs without tabit's hooks, so tabit
  cannot always tell which session it holds; that session may show in the
  list. Open the tab again to fix it.
