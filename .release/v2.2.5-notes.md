## v2.2.5 · Ginger Duck + Douhua

Tabit Chat now works with Grok tabs too, and shows how much of your Grok
quota is left.

### New
- **Grok tabs in the chat.** Open a Grok tab as a chat, like a Claude or
  Codex tab: what you typed, what Grok said, the tools it ran and their
  results show in the chat. Messages you send from the chat are typed
  into the tab.
- **Stop works for Grok.** Stop presses Ctrl+C in the tab, once, and only
  while Grok works and its message box is empty (with text in the box,
  Ctrl+C would only clear it). A stopped turn shows as "Interrupted.". If
  Grok has not stopped after 3 seconds, for example because it asks about
  its sub-agents, the chat says to answer in the tab.
- **Tab talk with Grok.** Grok and other AI tabs send each other messages
  with `@name:`, both ways.
- **Grok usage.** The usage list shows a Grok row (for example
  `Grok · Default 7d 16% ↺3d`). Tabit asks Grok for it at most every 10
  minutes. It sends no prompt and uses no quota.

### Fixed
- **A path with Chinese in its name opens.** A path in a reply only
  became a link when its name was all ASCII. Now a name may hold any
  letters, so `/home/chris/a/交接包_重點整理.html` opens with a tap.

### Notes
- Restart tabit (or let the update do it), then refresh the chat page.
- A Grok chat's settings only rename it. Its login and model are set in
  the tab itself.
- A message to a Grok tab that ends in `@word` gets a space at the end,
  so Grok's file picker does not take the Enter.
- A path written straight before Chinese text with no space (`/a/b.md裡`)
  takes that text into the link. Replies usually put a space or backticks
  there.
- How the Grok usage row behaves when Grok is logged out was not tested.
