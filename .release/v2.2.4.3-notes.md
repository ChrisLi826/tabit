## v2.2.4.3 · Ginger Duck + Scallion Pancake

A hotfix: an AI that only names another tab no longer sends it its reply,
and a tab stopped early no longer shows working.

### Fixed
- **An AI calls a tab with `@name:`.** A reply line that started with
  `@name` sent the whole reply to that tab, also when the AI only talked
  about it ("@ecw220v3 agrees with my review"). The other tab then got a
  message meant for you. Now a line calls a tab, or a group member, only
  when it starts with the name and a colon: `@name: ...` (or
  `@ann, @ben: ...`; a Chinese colon works too). Without the colon the
  name is only a mention. Every AI tab and group member is told this with
  each prompt.
- **A tab stopped before Claude answered no longer shows working.** Such a
  stop runs no hook. Tabit knew only of an Esc it saw itself, and forgot
  it when it restarted, so the tab showed working until its next prompt.
  Now a tab whose screen shows no busy line and has not changed for 30
  seconds is no longer working.

### Notes
- Restart tabit (or let the update do it) to get it. Each AI tab hears the
  new `@name:` rule with its next prompt.
- What you type yourself is not changed: `@name ...` at the start of your
  message still sends it to that tab or member.
- A reply that stalls for over 30 seconds with nothing moving on screen
  shows idle for that time, and working again when it moves on.
