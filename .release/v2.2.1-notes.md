## v2.2.1 · Ginger Duck + Tea Egg

Tabit Chat and the Claude tabs become one: every Claude tab has a chat, and
the tabs can talk to each other.

### New
- **Every Claude tab has a chat.** The chat has the tab's name and group,
  shows its conversation, and types into it. A new chat opens a Claude tab;
  deleting a chat closes its tab. A chat's settings switch the tab's account
  and model (the tab restarts in place, on the same conversation).
- **Menus on a tab's screen** (the folder trust question, numbered
  permission questions) show as cards with the whole prompt. Tap a choice;
  tabit presses the keys and checks the menu before every key.
- **Old chats move into tabs** when idle, with their history, picture, name
  and groups. The old folder is kept as `<id>.moved`.
- **AI tabs talk to each other.** When a line of a Claude tab's reply starts
  with `@name`, tabit types the reply into that tab, marked `[from @me]`.
  Every Claude tab is told its own name and the others with each prompt.
- **Call tabs from a chat.** A message that starts with `@a @b` (commas or
  not) goes only to those tabs, as in a group.
- **Type `@`** in the text box for a list of the names to call.
- **Groups** can hold the chats of tabs. There is no default Chat group: a
  chat with no group is in none.
- **Status bubbles** on each chat's picture: working, waiting for you,
  ready, agents in the background, exited. Remote shows "background" too.
- **The Remote address opens Tabit Chat.** The terminal view is at
  `/terminal` (⌨ in the chat).
- Remote's icon wears a purple chat bubble, so it differs from the desktop
  app's.
- On a phone, the owl and Chats/Groups fold away while you scroll the list.

### Fixed
- The list shows the time of the last message, not of the last save.
- An open chat comes back by itself after tabit restarts.
- A message sent while a tab works shows in its chat.
- The 🔔 rings for a tab's chat when the tab is done.
- After an account switch, a chat no longer shows its past again as a new
  conversation.
- Switching the model or account of a tab that never spoke no longer drops
  it to a shell.
- `@tabit.py` or a line in a code block is not taken as a call.

### Notes
- **A change in behaviour:** a chat message that starts with `@name` now
  goes to that tab, not to the chat you are in. Put the name later in the
  sentence ("ask @b ...") to have this chat's Claude do the asking.
- Tabs that talk to each other have no "Send to tab" card and no limit:
  two tabs that keep answering each other go on until you press Stop (Esc)
  in one of them. The "Allow typing into tabs" switch stops them too.
- A Remote app added to a phone's home screen before this release now opens
  the chat. The terminal view is at `/terminal`.
- See `docs/chat.md` for the whole guide.
