## v2.3.3 · Sesame Oil Chicken + Nougat

Tabit Chat takes many files at once, keeps the uploads folder small, and
shows who passed a message to whom.

### New
- **Drag files into a chat.** On a computer, drag one or more files anywhere
  on an open chat. The message box shows "Drop to attach", and the files go
  in, in order. Without a chat open, a drop does nothing.
- **📎 takes several at once.** Pick many photos or files in one go, on an
  iPhone too.
- **Uploads folder size and cleaning.** Web ⚙ Settings and **Settings… →
  Remote** on the computer show how big the uploads folder is
  (`~/.local/share/tabit/uploads`: what the pages and Nearby got).
  - **Every hour, delete files older than N days**: off unless you turn it
    on; 30 days by default.
  - **Delete them now** deletes the old ones at once.
  - Only the day folders tabit made are deleted.
- **"a → b" on passed-on messages.** When one chat passes a message to
  another, the message's name line says `ann → ben`, in place of a line of
  its own.
- **Pictures from every shelf.** New chat rolls its picture from Animals,
  Work, Rides and Sport. 🎲 rolls only from the shelf shown.

### Changed
- **Groups list the newest message first**, as Chats do.

### Fixed
- **A Claude tab showed as Grok.** When Claude in a tab ran Grok (for
  example for a review), Grok's status took over the tab: the chat read
  Grok's transcript and showed `grok-4.7`. A Grok that Claude runs no
  longer reports for the tab.

### Notes
- Restart tabit (or let the update do it), then refresh the pages.
