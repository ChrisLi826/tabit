## v1.8.3 · Tube Rice Pudding

Ctrl+click a file path in a terminal and it opens. Agent output is full of
paths, and reaching one used to mean selecting it and pasting it somewhere
else.

### Added
- **Ctrl+click a file path in a terminal** opens it. Absolute and `~/` paths
  match, with an optional `:line` suffix as compilers and `grep -n` print it.
  Hover underlines the match; right-click adds **Open Path** / **Copy Path**.
- **What happens depends on the file, not its suffix.** A text file — decided
  by reading its head, so `Makefile` counts — becomes a note tab with the
  cursor on `:line`. An `.html` page opens in your browser, and right-click
  adds **Open as Note** when its source is what you wanted. Anything else
  goes to the desktop's own handler.
- **The browser is the one that handles `http`,** not the `text/html`
  handler. Another app can claim `text/html` and then a local page opens
  somewhere you never meant.
- **IPv6 URLs are clickable** for the first time: the URL matcher now accepts
  a bracketed host.

### Hardened
Terminal output is attacker-influenced — a log line, a filename in a repo,
an SSH banner — so the matching is narrow and the dispatch never guesses.
Three independent reviews cross-examined each other; these are what survived.

- **An OSC 8 hyperlink names its own target, so it is always a URI.** A link
  reading "click here for help" whose target is `~/.ssh/id_rsa` must not open
  that key. VTE says which matcher fired; tabit carries that through instead
  of re-deriving it from the text.
- **A match may not start at the slash after a dot.** `./etc/passwd` in a log
  used to open `/etc/passwd`, resolved against tabit's own directory rather
  than the terminal's.
- **An IPv6 URL's path half is no longer taken as a local file.** The URL
  pattern rejected brackets, so `http://[::1]/home/you/.ssh/id_rsa` failed as
  a URL and the path matcher took the tail.
- **`:number` is a line number only when what is left opens as a note.**
  `open /dev/ttyUSB0:115200 failed` used to hand a live serial port to the
  desktop handler. The parse is bounded, too: a number past 2³¹ raises from
  GTK and 5000 digits trips Python's integer limit.
- **Sentence punctuation is trimmed from URLs but never from paths.** A file
  may really end in a dot and `..` is a real directory, so the exact string
  wins and the trimmed form is only a fallback.

### Fixed
- **The note size guard reads rather than trusting `stat`.** A `/proc` file
  reports size 0 and still reads 15MB, so the 5MB limit never applied to one.
  This affects the file chooser as well, not just the new click.
- **The long-line limit applies to the new entrance.** A minified JSON or JS
  file under 5MB went straight into the editor, which freezes it.
- **A short binary file no longer counts as text.** The
  cut-multibyte-character exemption ran on a probe that had not filled up, so
  `hello\xff` opened as a note — and saving it rewrote the original bytes.
- **The cursor-placement timer joins the note timers the close handler drops.**
  Closing the tab within 80ms of the click touched a destroyed view.

### Known limits
Paths with spaces or non-ASCII characters match only up to the first such
character. Widening the pattern makes a serial log line match as one path and
underlines half of every JSON dump, so the limit stays.

### Upgrade

```sh
cd tabit && git pull && ./install.sh
```
