## v2.2.2 · Ginger Duck + Twin Doughnut

Codex joins Tabit Chat next to Claude, every AI tab's chat can switch its
account, model and thinking effort, and the chat list shows how much of
each login's limits is used.

### New
- **Codex tabs have a chat.** It shows the Codex conversation (commands,
  their output, file edits), types into the tab, shows its status, and turns
  Codex's "run this command?" question into a card you tap. New chat asks
  which AI to open: Claude or Codex.
- **Codex accounts.** Settings adds Codex accounts next to the Claude ones.
  From the phone, a login shows a link and a one-time code to type there.
  Accounts share Codex's settings, sessions and program; only the login is
  their own.
- **Switch account, model and thinking effort** from a chat's settings, for
  Claude and Codex tabs. The tab restarts in place on the same conversation.
  The choice lives in that tab's command only: other tabs and the CLI's own
  settings files are not changed. Codex lists the models and efforts its own
  `/model` picker has.
- **Usage at the top of the chat list:** one row per AI login the chats use
  (Claude · Default, Claude · Personal, Codex · Default), with each limit
  window (5h, 7d, or Codex's 30d on a free plan), the share used, and when
  it starts again.
- **Per-chat Claude accounts** and **Settings inside the chat** (⚙).
- **Files open over the chat**, and file paths in a reply are links.
- **Answered question cards** keep your picks lit.
- **Background status** (↻) also counts shells and monitors still running,
  not only agents.
- The chat column is wider on a wide screen.
- Remote: pager keys (PgUp/PgDn, Home/End) in the key grid.

### Changed
- **No main chat.** The owl and its *Tabit Chat* leave the list. Its folder
  stays as `~/.local/share/tabit/chats/<id>.retired`, history and all.

### Fixed
- A Codex tab comes back to its own conversation after tabit restarts.
  Codex 0.166 keeps every session file in one shared background server, and
  tabit could not tell which session was the tab's (or took another tab's).
- A Codex menu with a long choice above the picked one showed no card.
- A tab's chat showed Claude Code's pasted-content tags.
- The chat's bell said nothing about being on or off, and did not ring
  while the page was behind another window.
- Remote: a pager at the end of a pipeline (`cat f | less`), or on a tab
  taller than 60 rows, now shows its whole screen.

### Notes
- tabit starts Codex with `-c notify=[...]` to learn which session a tab
  runs; a Codex chat fills in after the first turn ends. A `notify` in your
  own `~/.codex/config.toml` is not run inside tabit tabs. Codex tabs saved
  before this release get it the next time their codex starts.
- Claude tabs now run tabit's status line program, which keeps the usage
  and then runs your own status line from `settings.json`. A running claude
  picks this up when it next starts; until then tabit asks Anthropic for the
  usage every 3 minutes, as Claude's own `/usage` does.
