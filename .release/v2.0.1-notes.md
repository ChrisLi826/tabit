## v2.0.1 · Peanut Ice Cream Roll

Remote is now an app you can install, and a shell tab on it works like a
terminal.

### Added
- **Install Remote as an app.** In Chrome or Edge, **Install** in the
  address bar opens the page in its own window, with its own icon. Android
  can install it too. The iPhone home-screen icon matches it.
- **Colours for every tab.** A shell, serial or command tab's screen shows
  the colours tabit draws, not only tmux tabs.
- **Set the list width.** On a laptop, drag the gap between the tab list
  and the open tab; double-click it to reset.
- **Set the text size.** A− / A+ change the size of a tab's screen.

### Changed
- **Keyboard mode by default.** Every tab but an AI tab opens in ⌨ mode,
  and each tab keeps the mode you pick when you switch away and back. In ⌨
  mode the text box is hidden, and on a computer the key buttons too.
- **Copy and paste as in a terminal** in ⌨ mode: Ctrl+Shift+C /
  Ctrl+Shift+V (Cmd+C / Cmd+V on a Mac). Ctrl+C is always ^C.
- **Faster screen in ⌨ mode:** it updates every second, and 0.1 s after
  each key.
- **Scroll up for more history.** Scrolling a tmux tab's screen to the top
  (a wheel, or a swipe on a phone) loads 200 more lines. The Earlier button
  is gone; **Latest** (an arrow to a bar) jumps back down.

### Fixed
- Arrow keys work in a pager such as `git show` or `less`.
- The cursor sits in the right place on a long line that wrapped in tabit.
- Selecting text no longer ends ⌨ mode.
- **Latest** goes all the way to the bottom.
- A long line on a tab's screen no longer pushes the buttons and Send off
  the right side of the page.
