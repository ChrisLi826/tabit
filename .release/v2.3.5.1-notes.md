## v2.3.5.1 · Sesame Oil Chicken + Iron Egg

"Background work still running" now says which work, and the list stays
current.

### Fixed
- **"Background work still running" did not say what runs.** Claude's
  Stop hook hands over the work it left running; tabit keeps that list and
  shows one line per task, like `shell: npm test (b1)`, under the note in
  Tabit Chat and on the phone, and in the tooltip of the ↻ icon in the tab
  list.
- **The tooltip kept an old list.** When the work changed but the tab
  stayed in the background state, the tooltip did not follow. Now it does.
- **An old list could show for a later turn.** A new prompt, or a new
  session in the tab, now drops the list a past turn left.
- A task with no description shows as `subagent (id)`, and a task with no
  id as `(?)`, not `(None)`.

### Notes
- Restart tabit (or let the update do it), then refresh the chat page.
- A claude already running keeps the hooks it started with: the list
  shows once its tab starts claude again.
