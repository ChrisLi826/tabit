## v1.8.3.2 · Tube Rice Pudding

A second hotfix on v1.8.3, keeping its codename. The wrapped-path fix in
v1.8.3.1 only reached the first row of a path; now it reaches all of them.

### Fixed
- **Every row of a wrapped path is clickable, not just the first.** VTE
  matches one logical line at a time, so the rows after a break carry no
  match at all -- and no regex can reach them, however it is written. The
  row under the pointer is the only way in, so the rows around it are
  stitched back together and searched there. A candidate is kept only when
  it names a real file and runs through the row that was clicked, so a
  neighbouring line does not open it too. VTE draws the hover underline
  itself and knows nothing of the stitching, so only the first row
  underlines; the click works on all of them.
- **A restored preview left a blank editor when it was switched off.** The
  source pane carried `no_show_all`, so the page's `show_all` skipped the
  editor inside it, and showing the container alone brought back an empty
  pane.

### Changed
- **A Markdown file opens as a document, full width.** Markdown is written
  to be read, so a Ctrl+clicked `.md` now opens rendered and takes the whole
  tab, the way a page or a picture does. `Ctrl+Alt+M` still swaps back to
  the source.

cd tabit && git pull && ./install.sh
