## v1.8.3.1 · Tube Rice Pudding

A hotfix on v1.8.3, keeping its codename. Ctrl+click reaches the files it
could not reach, and shows them the way they are meant to be seen.

### Fixed
- **A path an app wrapped onto a second line can be clicked.** A terminal
  folds a long line itself and VTE matches straight through the fold, but an
  app that wraps its own output writes a real newline, which ended the match
  early — and tmux pads the row out to the right edge first, so the break sat
  behind a run of spaces. The rejoin only runs on a path that does not
  already name a file, and is only kept if the result does, so `ERROR in
  /etc/hosts` followed by `retry` still means /etc/hosts. A fold that lands
  on a slash leaves a real directory behind, which is why resolving is not
  enough to stop.
- **A rendered file came back as markup after a tab switch.** Switching tabs
  runs `show_all` on the page, which undoes a plain `hide()`, so the page
  reappeared as its source with the Preview button still lit. The same bug
  was already there for Markdown: preview switched off came back on.
- **An image or a PDF could be overwritten with an empty file.** Nothing is
  read into the buffer for those, so saving one wrote nothing over it. Both
  Save and Save As are refused now — Save As is no safer, its chooser opens
  on the file's own path.

### Changed
- **A file opens rendered, full width, rather than as its markup.** `.html`,
  `.svg`, `.pdf` and images (`.png` `.jpg` `.gif` `.webp` `.bmp` `.ico`)
  all paint in the tab instead of going out to the desktop's handler.
  `Ctrl+Alt+M` swaps to the source where there is any; right-click →
  **Open in Browser** hands the file over. The browser is the one that
  handles `http`, not the `text/html` handler, which another app can claim.
- **The preview toggle is remembered** across restarts, per file.
- **`+ Note` is now `+ Open`** — the tab holds a file as often as a scratch
  buffer, and the button already offered both.
