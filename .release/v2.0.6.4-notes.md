## v2.0.6.4 · Danzai Noodles + Hot Grass Jelly

A hotfix: the phone can type into a tmux tab that is scrolled up in tabit.

### Fixed
- **Typing from the Remote page or Telegram reaches a scrolled-up tmux
  tab.** Scrolling a tmux tab up in tabit puts tmux in copy mode, where it
  takes keys as its own commands, so a message from the phone never got to
  the agent. tabit now brings the tab back to the bottom first, then types.

### Notes
- A tab outside tmux never had this problem: scrolling it up only moves the
  view, and typing still goes to the program.
