## v2.0.2 · Danzai Noodles + Mango Shaved Ice

A new logo, Find in page previews, and Remote setup that shows where it
waits for you.

### Added
- **New logo** in the agent status colours: the tabs are red, green and
  yellow, and the open tab is a dark panel framed in blue.
- **Find in a page preview.** Find searches an HTML or Markdown preview
  shown full width. The current match is cyan and the others yellow, easy
  to see on a dark page, and Match Case and Whole Word work.
- **Remote setup shows where it waits for you.** When setup needs you (log
  in to Tailscale, turn on Serve, approve this computer), the bottom of the
  sidebar says which step, with an **open** link to the page.
- **Settings → Remote shows a link** to the page, with a copy button.
- **JSON Format puts the cursor where bad JSON stops**, so you can see the
  line.

### Fixed
- Remote keeps a plain tab's colours when the screen has Chinese text.
- Closing tabit or turning Remote off ends a Tailscale login that is still
  waiting, so the next start begins a fresh one.

### Safety
- Find runs its own script in a page preview, apart from the page. A
  Markdown preview still runs no script from the file.

### Changed
- Release codenames now pair a Taiwan main dish for the major version with
  a snack or drink for each release.

### Notes
- An installed Remote app or home-screen icon keeps the old logo: remove it
  and add it again. On Ubuntu, the dock may need Alt+F2, `r` (X11) or a new
  login to show the new icon.
