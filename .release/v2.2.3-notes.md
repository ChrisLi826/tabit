## v2.2.3 · Ginger Duck + Pepper Bun

Tabit Chat now looks like the AI's own terminal, with its colors and real
tables, and a message sent while the AI works shows as queued and can be
taken back.

### New
- **Queued messages you can take back.** A message sent while a Claude tab
  works waits until Claude finishes its current step. The chat now shows it
  at once as a pale **Queued** bubble. **Take back** pulls it out of Claude's
  queue and puts it back in your message box, to change or delete; the other
  queued messages stay queued. The bubble turns normal when Claude reads it.
- **Colors like the terminal.** In a Claude chat, `code` and **bold** have
  Claude's colors. A Codex chat uses the colors of Codex's default theme
  (catppuccin-mocha): headings by level (red, orange, yellow, green, ...),
  red bold and italic, green code, teal bullets, pink quotes, blue links.
  In a group, each member's words have its own AI's colors.
- **Code blocks have syntax colors:** keys, strings, numbers, keywords and
  comments.
- **Tables are real tables**, with a grid, like in the terminal.
- **File changes** show added lines green and removed lines red.

### Fixed
- A code block indented under a list item showed its ```` ``` ```` marks
  instead of a code block.
- Bold text holding `code` showed its `**` marks.
- `*Italic*` showed its stars.

### Notes
- Refresh the chat page (on the phone too) to get the new look.
- Take back works while the tab's own message box is empty (Claude Code
  then shows "Press up to edit queued messages"). With your own text in the
  tab's box, take the message back in the tab. tabit takes it back the way
  you would: it presses Up in the tab, empties the box, and types the other
  queued messages again.
- Codex reads a message as soon as it arrives, so nothing waits there and
  there is nothing to take back.
