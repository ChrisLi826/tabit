## v2.0.6 · Danzai Noodles + Hot Grass Jelly

Change the Tailscale account Remote uses from Settings, and resume a
Claude session that runs in the background.

### Added
- **Tailscale account in Settings → Remote.** The page shows the account
  Remote lets in, with **Switch account** (the other accounts known on
  this computer, or **Log in with another account…**, whose login page
  opens in the browser) and **Log out**, which asks first. Remote starts
  again by itself, so it lets in the new account. When Tailscale needs
  more rights, tabit's password window asks.

### Fixed
- **+ AI resume opens a session running in the background.** Claude
  refuses `--resume` for one; tabit now opens it with `claude attach`,
  now and after a restart, instead of saying it found no session.
- The session list, and Resume session with no id, leave out every
  Claude session already running, in another terminal or in the
  background, so neither offers one that is open.

### Notes
- Another account is another tailnet: the page address changes, and the
  phone's Tailscale must use that account too.
- After Log out, Remote stops until this computer logs in again; with
  Remote on, tabit asks to log in, with any account.
