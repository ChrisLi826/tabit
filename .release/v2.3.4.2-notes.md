## v2.3.4.2 · Sesame Oil Chicken + Egg Roll

Tabit Chat no longer shows a line Claude already read as queued, sends a
message once, and copies a code block in one tap.

### Fixed
- **A line Claude had answered still showed as "Queued".** The chat
  follows Claude Code's queue in its transcript, but Claude does not always
  take the first queued line, so one wrong step could stay for days. A tab
  that is not working holds nothing, so now the chat clears its queue once
  the tab has been calm (idle, done, background work only, or closed) for
  two looks in a row.
- **One message sent twice.** Enter pressed again while a message was
  still being sent sent it again. The page now sends one at a time.
- **The top-right message went off the right edge on a zoomed phone.**

### New
- **Copy on code blocks.** Each code block in a reply has **Copy** at its
  top right.

### Notes
- Restart tabit (or let the update do it), then refresh the chat page.
