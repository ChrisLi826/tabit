## v2.4.0.1 · Railway Bento + Brown Sugar Ginger Tea

Tabit Chat on an iPhone keeps the box where you type next to the keyboard,
and a menu Claude shows before it starts work comes as buttons.

### Fixed
- **The keyboard on an iPhone.** The message box and the search box now sit
  just above the keyboard. Before, the box was hidden at first and then
  went up too far, with the home bar's gap still under it. The Planner's
  chat box and its New box follow the keyboard too.
- **"Resume this conversation?" had no buttons.** Claude Code asks this
  before a message to a long idle conversation goes in. No hook runs for
  it, so tabit took the tab for idle and Tabit Chat showed no question.
  Now the tab waits for you and the menu comes as buttons.
