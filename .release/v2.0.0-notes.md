## v2.0.0 · Pineapple Cake

Every piece of work becomes a tab you manage, and now the tabs go with
you. **Remote** puts tabit's tab list on your phone or laptop, live, over
your own Tailscale. And tabit has a new logo.

### Added
- **Remote: your tabs on your phone.** Settings… → Remote serves a page to
  your own devices only, through Tailscale Serve. It shows every group and
  tab, and which agents need you, updated live. Add it to the home screen
  on a phone.
- **Remote sets up Tailscale for you.** Turning it on installs Tailscale,
  starts it, signs you in and turns on Serve, asking once first.
- **Type into a tab from the page** (a switch, off by default): read the
  tab's screen with its colours, answer an agent, run a command, or use a
  serial console. A ⌨ mode sends each key straight in. Attach a file or a
  screenshot; it is saved under `~/.local/share/tabit/uploads/`.
- **Manage tabs and groups from the page:** open a Terminal, an AI or a
  Command; rename, move, regroup or close a tab; rename, recolour,
  collapse or remove a group.
- **Read files from the page** (a second switch): tap a path or a note
  tab. Text, Markdown laid out, and png, jpg, gif, webp and svg images, up
  to 2 MB, under your home or `/tmp`.
- **A laptop layout:** in a wide browser the page looks like tabit itself,
  with the tab list on the left. 🔔 shows a notice when an agent finishes
  or wants you.
- **New logo**, also the page's icon and the iPhone home-screen icon.
- **New README**, with the details moved into `docs/`.

### Changed
- **Closing a tab only ends the tmux sessions tabit made** for its AI
  tabs. A tmux session of your own, opened with + tmux, is only detached:
  it keeps running and you can attach again.
- The name is written **tabit**, all lower case.

### Fixed
- `sessions.json` and `settings.json` are never left half written, and a
  file tabit cannot read or set aside is never saved over.
- A restored tab that dies at once stays in the list and keeps its folder.
  Group names survive a start where the tab list could not be read.
- tmux sessions are matched by their exact name, so closing a tab never
  ends `dev2` when it meant `dev`, and never one another tab still uses.
- A + Command that runs tmux on another host (`ssh … tmux attach`) never
  ends a local session of the same name.
- Old tmux AI tabs are rewrapped on restore.
- Esc or the window's × on the "save this note?" prompt keeps the note.
- Telegram: nothing from an old bot or chat acts after you switch.
- A link clicked in a note preview opens in your browser.
- One broken tab no longer stops the agent status updates of the others.
- A wrong value hand-typed in `settings.json` (`true`, `NaN`, a huge
  number) reads as the default instead of stopping tabit from starting.

### Safety
- Only your own Tailscale login gets in. Other people on a shared tailnet
  get 403, and a POST must come from the page itself.
- Every file the page opens is sent with a sandbox policy, so an HTML,
  Markdown or SVG file cannot run a script. Keys, password files and
  tabit's own settings are never shown.
- Note previews (Markdown and YAML) run no script from the file and cannot
  read other local files. A note cannot load a web page by itself.
- A fetched agent list cannot write outside its cache folder.

### Notes
- Remote needs Tailscale on this computer and on the phone, signed in to
  the same account. Tailscale serves the page only for a user who may also
  use sudo.
- On iPhone, a home-screen icon added before this release keeps the old
  logo: remove it and add it again.
