## v2.0.4 · Danzai Noodles + Sun Cake

Update Now knows where tabit came from, and never touches work in
progress.

### Changed
- **Update Now finds the folder tabit was installed from.** `install.sh`
  records it, so a git checkout anywhere is found, not only `~/tabit`. A
  tabit installed from a release download updates as a release.
- **Work in progress is left alone.** A checkout on another branch, on no
  branch, or in the middle of a rebase or merge is not touched: Update
  installs the release from GitHub instead, and the folder stays as it
  is. A clash with your own changes on `main` still stops and says what
  to run.

### Fixed
- The update dialog's error line and log wrap instead of running off
  the window.

### Notes
- An install made before this release has no record yet, so Update still
  looks in `~/tabit` once; the next install writes the record.
- After Update installs the release over a tabit you built from your own
  branch, run `./install.sh` in your folder to go back to your build.
