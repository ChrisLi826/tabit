## v1.8.2 · Iron Egg

Clickable links, a grouped shortcut list, a sidebar AI summary, Ctrl+Tab
jump-back — and the defects a review pass found in them.

### Added
- **Ctrl+click a URL in a terminal** opens it. Hover underlines the match;
  right-click a link adds **Open Link** / **Copy Link**. Plain `http(s)://` /
  `ftp://` text and OSC 8 hyperlinks both work. The pattern stops at brackets
  and quotes, so JSON dumps, serial logs and Connect argv stay clean.
- **Ctrl+Tab jumps back to the last tab you stayed on** when no right pane is
  open (press again to come back). Tabs you only passed through do not count:
  a tab is "stayed on" once it has held the selection for 0.8s *and* the
  modifier is released, so holding Ctrl through a run of
  `Ctrl+PageUp`/`PageDown` is one move however long it pauses on the way.
- **The sidebar foot counts every AI tab** by status, collapsed groups
  included, next to a clock. The off-viewport peeks only cover tabs scrolled
  out of sight; this row cannot miss an agent waiting on you. Click a count to
  jump to that agent, click again to cycle.
- **The Shortcuts dialog is grouped** — New session, Session, Order & groups,
  Split panes, Note, Find, Clipboard — instead of one flat list cut down the
  middle. The two columns hold whole groups and rebalance as shortcuts are
  added.
- **Connect tabs running in tmux have their own icon**: the teal mark in the
  purple tmux frame, matching how AI tabs are marked. It is chosen from argv,
  so tabs restored from `sessions.json` get it too.

### Fixed
- **"Force reconnect" is a one-off action again.** It was baked into argv as
  `sh -c "tmux kill-session …"`, which is replayed on every start, so each
  restart killed the session and ran the whole cloud login again instead of
  attaching — and the tick was remembered, so every new Connect tab inherited
  it.
- **AI tmux session names are stable across restarts.** The digest came from
  `hash()`, which Python randomises per process, so `+AI` with Resume opened a
  second agent instead of attaching to the first.
- **Update failures say why.** Both error callbacks are deferred to the GTK
  thread but read the `except … as e` variable, which Python clears when the
  block ends: the callback raised `NameError`, so no message appeared and
  Close stayed insensitive.
- **Opening a link no longer leaves a busy cursor** spinning over the window.
  A launch context sets `DESKTOP_STARTUP_ID`, and a browser already running
  hands the URL to its existing process and exits without mapping a window,
  so the startup sequence never completed.
- **An OSC 8 hyperlink keeps its trailing punctuation** — the escape states
  where the URI ends, so trimming it changed what was opened.
- **Jump-back corrections:** losing window focus now ends a gesture (a
  modifier released in another window never reported back); Ctrl+Tab while a
  tab is still settling goes to the last committed tab rather than the one
  before it; and closing the settled tab no longer displaces a live target
  with a dead row.
