## v2.2.4 · Ginger Duck + Scallion Pancake

Tabit Chat now runs the AI's slash commands and skills, and shows the
screens they open in the tab, right over the message box.

### New
- **`/` lists commands and skills.** Type `/` at the start of the message
  box: the list has the AI's main built-in commands (`/compact`, `/clear`,
  `/context`, `/init`, ... for Claude; `/review`, `/init`, `/new`, ... for
  Codex) and the skills that tab really has, read from its own transcript.
  Type more to filter; a tap, Enter or Tab puts it in the box, ready for
  its words. A Codex skill goes in as `$name` (`$` lists them too). A new
  Claude tab shows the skills of the last conversation in the same folder
  until its first message.
- **Commands show in the chat.** A command the tab ran, from the chat or
  at the desk, shows as your line (`/context`, `/grilling my plan`), and
  what it printed shows under it as **⌘ output**.
- **The tab's screen over the chat.** A command that opens a screen in the
  tab (`/usage`, `/status`, `/diff`, `/mcp`, ...) opens a box with that
  screen, read again every 1.5 s. Work it with the arrow, Tab, Enter and
  Esc buttons, or, on a computer, straight from the keyboard while the box
  has the focus. Drag the bar on top to make it taller or shorter (or use
  − and ＋); the height is kept. **Close** closes the tab's screen too.
  When the screen is closed at the desk, the box goes by itself.
- **Messages wait while a screen is open.** A message sent while a Claude
  tab shows one of its screens would close it if typed. It now waits as a
  **Queued** bubble, can be taken back, and goes in, in order, when the
  screen closes. The chat then shows that screen, so one left open is easy
  to find and close.

### Fixed
- A test of the usage block failed now and then: it did not wait for the
  file the usage is kept in.

### Notes
- Refresh the chat page (on the phone too) to get the new parts.
- Model, effort and account are not in the `/` list: the chat's own
  settings switch them for that tab only.
- Some Claude skills may only be started by Claude itself. Picking one,
  Claude Code answers that it cannot be started by name.
- Esc is pressed only while the tab's screen is still open, since Esc stops
  a Claude that is working. A Claude screen counts as open while Claude's
  own message box is hidden.
- A waiting message is kept in tabit's memory: restarting tabit before the
  screen closes drops it.
- The Codex `/` list was checked against a real Codex session file, not
  clicked in a live Codex chat.
