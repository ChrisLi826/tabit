## v2.2.1.1 · Ginger Duck + Tea Egg

A hotfix: a chat message that ends in a file path goes out the first time.

### Fixed
- **A message whose last line is a file path is sent at once.** With a
  picture attached, the path is the last line, and Claude Code lost the
  Enter while it read the file. The text waited in the tab's box and went
  out with your next message, so several messages became one. tabit now
  presses Enter a moment after the text.
- Two messages sent one right after the other stay two messages.

### Notes
- The same fix covers tasks sent to a tab from Telegram.
- Restart tabit (or let the update do it) to get it.
