## v2.2.6 · Ginger Duck + Mochi

The usage rows at the top of the chat list now pick which chats you see.

### New
- **Tap a login to see its chats.** Tap a usage row (`Claude · Personal`,
  `Grok · Default`, ...) and the list keeps only the chats that use that
  login. Tap more rows to add their chats too; tap a picked row again to
  drop it. The rows not picked fade, and with none picked all chats show.
- **Groups too.** On the Groups tab, a group shows when one of its
  members uses a picked login.
- **Chat count per login.** Each usage row shows how many chats use that
  login, for example `Claude · Personal (5)`.

### Notes
- Refresh the chat page (on the phone too) to get it. No restart needed.
- The pick works with the search box, and it is gone after a page reload.
- The count is always of chats, also on the Groups tab.
